# API Documentation

This directory hosts documentation for the Smart Agricultural Product Inventory Management System.

## JSDoc Generation

Interactive HTML API documentation can be generated from the codebase comments by running:

```bash
npm run docs
```

The generated documentation is placed in `docs/api/` (which is excluded from Git tracking via `.gitignore`).
Once generated, you can open `docs/api/index.html` in any web browser to explore classes, functions, and architecture layers.
